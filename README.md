## 🎮 Що вміє гра

<details>
<summary><b>⚡ Апгрейд</b> — натисни щоб розгорнути</summary>

<br>

- **Три режими входу:**
  - Один скін
  - Мульти-апгрейд (2–10 предметів)
  - Кредити

- **Два режими ролу:**
  - **Понад** (за замовчуванням) — виграш дає +5% вартості цілі у DC
  - **Під** — захист, +15% до шансу, максимум 60%

- **Формула шансу:**
  ```
  chance = 100 × (input / target)^1.05 × 0.45
  ```

- **Анімація:** canvas-градусник із покажчиком, що проходить 5 обертів за 3.2 секунди

</details>

<details>
<summary><b>📦 Кейси</b> — 4 типи з різними шансами</summary>

<br>

| Кейс | Ціна | 🟢 Звичайний | 🔵 Незвичний | 🟣 Рідкісний | 🟡 Легендарний |
|:-----|:----:|:-----------:|:------------:|:-----------:|:-------------:|
| Бюджетний   | 100 DC   | 95%  | 4%    | 0.9% | 0.1% |
| Стандартний | 300 DC   | 90%  | 7.5%  | 2%   | 0.5% |
| Преміум     | 1 000 DC | 60%  | 30%   | 8%   | 2%   |
| Легендарний | 5 000 DC | 20%  | 50%   | 25%  | 5%   |

- 🎰 **Анімована reel-стрічка** — 50 карток, покажчик зупиняється через 4.4 секунди
- 🎁 **Безкоштовний кейс** — раз на 24 години, тільки предмети до 300 DC

</details>

<details>
<summary><b>⚔️ Бій 1v1</b> — монетка вирішує все</summary>

<br>

- Обери свій предмет — бот підбере схожий за ціною (±35%)
- **3D-монетка CS** обертається навколо осі X
- Зупиняється на «ТИ» або «БОТ»
- 🏆 Переможець забирає предмет суперника

</details>

<details>
<summary><b>👑 Battle Royale</b> — 4 гравці, 1 переможець</summary>

<br>

- 🎯 4 гравці (ти + 3 боти)
- 🪙 Плей-оф на монетках: півфінали → фінал
- 🏆 Переможець забирає предмети **всіх ботів** (3 шт.)
- 💾 Свій предмет **залишається** при перемозі *(фікс у 3.6)*

</details>

<details>
<summary><b>📜 Контракт (Trade-Up)</b> — 5 в 1</summary>

<br>

- 💼 Вклади **5 предметів** → отримай **1 випадковий**
- 📊 Очікуваний діапазон: `0.75× – 1.35×` від суми
- 🔥 Всі 5 предметів споживаються назавжди

</details>

<details>
<summary><b>🎯 Завдання й прогресія</b></summary>

<br>

- 📅 **5 щоденних завдань** (оновлюються о 00:00)
- 📆 **3 щотижневі місії** (скидаються в понеділок)
- 🏅 **23 досягнення** (від «перший ролл» до «завершити всі колекції»)
- 🗂 **3 колекції** (снайперські / гвинтівки / пістолети) — за кожну **ексклюзивний предмет** + бонусні DC
- 📈 **Рівні й престиж:** кожні 750 XP = рівень · після LVL 10 → престиж (+10% XP назавжди)

</details>

- 🔍 **Фільтри:** гвинтівки · пістолети · ножі · рукавиці · ПП · важка · снайперські

Завантажується з **трьох джерел по черзі** (якщо одне впало — наступне):

- 📝 Назвою дизайну скіна
- 💧 Водяним знаком «POTUZHNO»

**Це гарантує, що жодна картка ніколи не буде пустою.**

## 🚀 Публікація на Netlify

### Спосіб 1: Drag & Drop ⚡

1. Завантаж папку в Git-репозиторій
2. У Netlify → **Deploys** → перетягни папку мишкою
3. ✅ Готово

### Спосіб 2: Git-деплой 🔧 *(рекомендовано)*

1. Залий папку в GitHub / GitLab / Bitbucket
2. Netlify → **New site from Git** → обери репозиторій
3. Налаштування вже вказані в `netlify.toml`:
   ```toml
   publish = "."
   functions = "netlify/functions"
   ```

### Що задеплоїться автоматично

| Тип | Шлях | Опис |
|:----|:-----|:-----|
| 📄 Статика | `/` | `index.html` + `assets/` |
| 🔐 Функція | `POST /api/steam/auth` | Початок Steam OpenID |
| 🎒 Функція | `GET /api/steam/inventory?steamid=...` | Предмети гравця |
| 📚 Функція | `GET /api/catalog/skins` | Проксі каталогу з кешем |

> [!NOTE]
> **HTTPS обов'язковий.** Steam OpenID не працює по HTTP. Netlify автоматично видає Let's Encrypt SSL — переконайся, що домен вказано з `https://`.

## 🔒 Безпека

`netlify.toml` містить обов'язкові headers:

```toml
[[headers]]
  for = "/*"
  [headers.values]
    X-Frame-Options = "DENY"
    X-Content-Type-Options = "nosniff"
    Referrer-Policy = "strict-origin-when-cross-origin"
```

| Header | Захищає від |
|:-------|:------------|
| `X-Frame-Options` | Clickjacking — сайт не можна вбудувати в iframe |
| `X-Content-Type-Options` | MIME-sniffing — браузер не вгадує типи файлів |
| `Referrer-Policy` | Витоку referrer'а на сторонні сайти |

## 🧪 Локальний запуск

Просто відкрий `index.html` у браузері.

| Що працює без бекенду | Що НЕ працює |
|:----------------------|:-------------|
| ⚡ Апгрейд | 🔐 Steam-логін |
| 📦 Кейси (з локальним каталогом) | 🌐 Повний каталог CS2 |
| ⚔️ Бій 1v1 | |
| 👑 Battle Royale | |
| 📜 Контракт | |
| 🎯 Завдання · ачівки · колекції | |

### Для повного тесту з функціями

```bash
# Встанови Netlify CLI
npm install -g netlify-cli

# Запусти локальний сервер із функціями
netlify dev
```

Сервер підніметься на `http://localhost:8888` із підтримкою всіх Netlify Functions.
