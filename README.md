# ПОТУЖНО DROP 2.0

Статична гра-пародія на сайти з апгрейдом CS2. Вона не приймає гроші або предмети, не створює Steam Trade Offers та не видає реальних призів.

## Що працює

- Віртуальний стартовий інвентар і демо-кредити, які зберігаються тільки у браузері.
- Вибір предмета, цілі, шанс, анімація ролу та віртуальний результат.
- Добовий бонус і скидання демо-гри.
- Необов'язковий вхід Steam: після входу створюються віртуальні копії **публічних** предметів CS2 для гри. Предмети не передаються сайту.
- Повний каталог CS2, включно з ножами та рукавицями. Він завантажується через Netlify-функцію з двома резервними джерелами.

## Публікація на Netlify

1. Завантажте цю папку в Git-репозиторій або перетягніть її у Netlify Deploys.
2. Для Git-деплою залиште `publish` як `.` та директорію функцій як `netlify/functions` — вони вже вказані у `netlify.toml`.
3. Netlify встановить залежність з `package.json` і задеплоїть функції за шляхами `/api/steam/auth`, `/api/steam/inventory` та `/api/catalog/skins`.
4. Переконайтеся, що адреса сайту працює через HTTPS; Steam OpenID повертає користувача на цю ж адресу.

## Важливо

Не додавайте депозитів, платного ігрового балансу, приймання скинів, трейд-ботів або посилань на переказ коштів заради шансів. Добровільна підтримка може бути лише окремою від гри й не може змінювати баланс, предмети або ймовірності.
