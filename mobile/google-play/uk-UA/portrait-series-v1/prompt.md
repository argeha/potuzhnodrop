# Декоративний фон вертикальної серії

Режим: вбудований image_gen. Одна фонова ілюстрація використовується для
єдиного стилю всієї серії. Знімки користувача не передавалися генератору:
ігровий UI збережено окремим шаром; кадрування та точні підписи описані
в `slides.json`, відтворюване компонування — у `export-portrait-series.mjs`.

## Фінальний промпт

Use case: ads-marketing.
Asset type: one reusable portrait promotional-background artwork for a Ukrainian virtual collection game called ПОТУЖНО DROP. Portrait 9:16, intended as 1080x1920.
Create an exceptionally polished but very restrained midnight-navy and warm-gold campaign backdrop. Dark graphite brushed-metal panels, subtle depth, a narrow beautiful amber rim-light arc along the far right edge, a tiny cobalt glow near the far upper left, extremely fine atmospheric grain. Premium contemporary gaming software, not fantasy royalty or casino.
Keep the central 82% of width and top 80% of height very dark, calm and visually uniform because real unmodified game screenshots will be placed there afterwards. Keep the bottom 20% mostly dark navy with a delicate gold glow along the very bottom edge so white-and-gold caption text will be added separately.
No UI, screenshots, text, letters, logos, people, coins, cash, weapons, cases, phones, device frames, particles, fireworks, score or rank badges, other objects, watermarks. The artwork is ONLY a decorative full-bleed background, not an app mockup. Beautiful subtle photographic material and light, generous negative space. Do not add any central object or type. Opaque background.
